# Remoting Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** pekko-py processes message each other's actors by path over TCP, with `ask` unchanged.

**Architecture:** `pekko_py/serialization.py` (registry and self-describing JSON codec with ref placeholders), `pekko_py/remote.py` (`UniqueAddress`, `RemoteRef`, temp-ref table, `Remoting` with listener, associations, framing, dispatch), and small hooks in `system.py` (`address=`, `remoting`, `resolve`). `cell.py` is untouched except that `ActorRef` gains a `__weakref__` slot so refs can be weakly held in the temp table.

**Tech Stack:** stdlib only (`asyncio` streams, `json`, `dataclasses`, `weakref`, `secrets`).

**Spec:** `docs/superpowers/specs/2026-10-24-remoting-design.md`

## Global Constraints

- Python `>=3.12`, core `dependencies = []`, `uv run pytest` and `uv run pyright` strict green after every task.
- Commits: hanishi commits on request. Do not run `git commit`.
- Tests run several systems in one process over loopback with a free-port helper in `tests/util.py`; no subprocesses; every test under the conftest leak check; no sleeps over 50ms except where a connect failure must time out.

## Review Focus

- A `tell` to a `RemoteRef` for a node that is down must never raise or block the caller; the message is dead-lettered once the connect fails. Task 3, `test_unreachable_node_dead_letters_without_blocking`.
- The ask reply ref must be reachable from the other node only while the ask is pending, and must not keep the asker alive forever. Task 2, `test_temp_refs_are_weak`.
- Resolving a `$ref` path that points at this system must yield the local ref object, so an actor receiving its own ref back compares equal. Task 2, `test_resolve_local_path_returns_the_local_ref`.
- A frame whose `to` does not exist must be a dead letter, not a dropped connection. Task 3, `test_unknown_recipient_is_a_dead_letter`.
- Terminating a system with open connections, a listener and queued frames must leak no task. Every Task 3 test, via conftest.

Decoding: `$type` → `cls(**fields)` with tuple-annotated fields rebuilt as tuples; `$ref` → `resolve(path)`.

### Task 3: Transport: listener, associations, framing, dispatch

**Files:**
- Modify: `src/pekko_py/remote.py`, `src/pekko_py/system.py` (`__aenter__` calls `await remoting.listen()`; `terminate` → `remoting.close()` scheduled before the root stop so `when_terminated` covers it)
- Test: `tests/test_remote.py`

**Interfaces:**
- Produces: `Remoting.listen() -> None` (asyncio `start_server` on the address; handler reads `hello`, then frames); `Remoting.send(path, msg)` (encode now, raising `SerializationError`; look up or create `Association(host, port)`; enqueue frame; the association's writer task connects, sends `hello`, drains the queue); `Remoting.offer(path, msg)` (same, then awaits the writer's `drain()`); `Remoting.close()` (closes listener, cancels reader/writer tasks, closes streams). `_Frame` helpers: `pack(obj) -> bytes`, `async read_frame(reader) -> Json | None`. Constants `MAX_FRAME = 16 * 2**20`, `QUEUE_BOUND = 1000`.
- Inbound dispatch: `hello` records the peer's `UniqueAddress` (log "restarted" if uid changed); `msg` → `resolve(to).tell(decode(message))`, `LookupError`/`SerializationError` → `system.dead_letter(raw, system)` and debug log.
